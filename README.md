## AI-Based Plant Disease Diagnosis System
# 📌 Overview

This project is an AI-powered plant disease detection system designed to help farmers identify diseases early and take corrective actions. It uses a Convolutional Neural Network (CNN) trained on plant leaf images to classify diseases accurately.
Once the disease is detected, an AI agent analyzes the result and suggests the most suitable pesticides or treatments based on the identified disease.

# 🚀 Features
🌿 Plant Disease Detection using a trained CNN model
🤖 AI Reasoning Agent to interpret disease predictions
💊 Pesticide & Treatment Recommendations
📸 Supports image input through the app
📈 High-accuracy prediction on common plant diseases
🧪 Fully reproducible model training pipeline

# 🧠 Technology Stack

##🎯 Goal of the Project
To support farmers and agricultural workers with fast, reliable, AI-driven plant health diagnosis and treatment suggestions, improving crop quality and reducing losses.
